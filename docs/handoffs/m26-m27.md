## 2. 新增接口与数据

冻结契约见 `docs/build-plan.md` M26/M27。主要入口：

```text
papermine web [--host] [--api-port] [--web-port] [--no-browser] [--dev]
POST /imports/folder
POST /imports/archive
GET  /imports/{import_id}
POST /imports/{import_id}/analyze
```

数据位置：

```text
~/.papermine/imports/<import_id>/source/
~/.papermine/imports/<import_id>/import.json
~/.papermine/runs/<run_id>/
```

`import.json` 使用 `import_record` schema v1；一个 import 可关联一个或多次后续 run，当前 UI 每次确认创建一个新 run。

## 3. 关键设计决策

1. 前端只请求同源 `/api`；`server.mjs` 使用 Node 内置 `http` 流式代理到 FastAPI。
2. 未使用 Next rewrite 传递运行时端口，因为实测 rewrite 目标会进入构建产物。
3. 文件上传使用 `python-multipart`，仅加入 `web` optional extra；核心依赖仍只有 `httpx`。
4. 导入与分析分两步，必须先返回预览，再由用户确认分析。
5. 文件夹上传依赖浏览器 `webkitdirectory` + `webkitRelativePath` 保留相对层级。

## 4. 安全与限制

- 拒绝绝对路径、`..` 路径、ZIP Slip 和 ZIP 符号链接。
- 单文件 20 MiB、总大小 500 MiB、最多 10,000 文件。
- 排除 `.git/node_modules/.venv/venv/__pycache__/.next/dist/build/coverage/.idea/.vscode`。
- 排除 `.env/*.pem/*.key/credentials.json/id_rsa` 并在预览中给出警告。
- ZIP 按文件流式解压；本地 Node 代理同样流式转发上传，不整包缓冲到内存。

## 6. 降级路径

- 无 LLM key 或网络失败：确认分析后沿用 Orchestrator 的确定性降级，导入本身不依赖 LLM。
- Node/npm 缺失、前端依赖未安装、构建失败：`papermine web` 返回可读错误，不启动半套服务。
- 后续修复：启动前检查 API/Web 端口是否被旧进程占用；健康检查成功后再次确认新子进程存活，避免旧服务响应造成误判和孤立前端。
- 后续体验增强：导入请求改用浏览器上传进度事件显示真实百分比；分析阶段不伪造百分比，显示不确定时长动画与实时耗时。素材根据用户提供的参考图重新绘制并本地抠图，已移除品牌文字/徽记，透明 Q 版鲸鱼科研助手位于 `web/frontend/public/whale-researcher.png`。
- 导入失败：返回 400/413，不创建 run；未完成的导入目录会清理。

## 7. 遗留问题

- 当前分析 API 是同步请求，长分析期间页面必须保持打开；后续可升级为后台 job + 轮询/事件流。
- 文件夹选择依赖 Chromium 系浏览器的 `webkitdirectory`；ZIP 是跨浏览器保底路径。
- 当前 UI 未提供删除导入副本、历史 import 列表或同一 import 再次分析入口。
- 未实现精确上传百分比，当前仅显示上传中状态；后续可用 XHR/分片上传补充。
